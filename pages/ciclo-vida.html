Diseño

Consiste en una plataforma web que conecta profesores y alumnos para ofrecer apoyo académico, priorizamos la accesibilidad, inclusión, seguridad y comodidad tanto para los profesores como para los alumnos, siempre lo que buscamos es permitir un crecimiento en la educcación.
Nuestro modelo enfoca también criterios de sostenibilidad, ya que reduce la necesidad del uso de transportes y por tanto reduce la contaminación, además de buscar una manera en la que el modelo educativo sea más eficiente y equitativo.

Desarrollo

En el desarrollo del proyecto priorizamos el hacer eficiente la página web para que esta consuma los menores recursos posibles, también aplicamos HTML semántico para mejorar la accesibilidad y el posicionamiento SEO, permitiendo a la mayor cantidad de usuarios de conocer y usar el servicio.
Por supuesto durante el desarrollo nos encargamos de perfeccionar un sistema de validación y reporte de usuarios para evitar posibles amenazas a la seguridad de cualquiera de los usuarios.

Uso

Durante el uso del servicio se busca que este sea lo más cómodo y accesible para los usuarios, permitiendo a los alumnos obtener una educación de calidad.
Gracias a que se usan métodos digitales este modelo es mucho más inclusivo para todos aquellos alumnos que tengan una disponibilad horaria reducida además de eliminar las barreras geográficas como pueden ser el hecho de querer estudiar algo que no se encuentra cerca de donde vives.

Mantenimiento

A la hora del mantenimiento del servicio nos comprometemos a llevar un módelo de negocio sostenible para poder expandir el servicio y mantenerlo con vida el mayor tiempo posible.
Además intentaremos escuchar siempre a la comunidad, implementar funciones deseadas y prestar mucha importancia al sistema de moderación de usuarios.

Fin de vida o reutilización

Se contempla que, en caso de que el proyecto deba terminarse se lleven a cabo una serie de medidas:
  • Publicación del código fuente como open source para permitir la reutilización de este y que se pueda usar para otros proyectos sostenibles.
  • Gestión responsable de los datos y, priorizar siempre la privacidad de los usuarios.
Con estas medidas aseguramos que el legado del proyecto se mantenga y permita la creación de proyectos independientes o a gran escala que sean positivos y sostenibles para la sociedad.

Aplicación de principios de ecodiseño en el servicio

  • Digitalización de proceso educativo, evitando materiales físicos y desplazamientos.
  • Reutilización de contenidos educativos mediantes la grabación de clases.

Aplicación de principios de ecodiseño en la página web

  • Optimización de recursos.
  • Optimización de código.
  • Estructura semántica de la web.
  • Diseño intuitivo para mejorar accesibilidad.
